ICS0027 / Checkpoint 1

Password manager

A course project for storing personal website credentials.

This is the initial project page. Login and password storage will be implemented in later checkpoints.

Planned features

  • Register and sign in with a master password.
  • Add, view, edit and delete your own saved credentials.
  • Encrypt vault entries before saving them in the database.
  • Log out and expire inactive sessions.

There are no working credential forms in this version.
